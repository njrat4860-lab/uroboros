# Уроборус

Поиск человека по фото на вебке в реальном времени.

## Запуск

1. Поставь Python 3.12 с python.org, при установке отметь Add to PATH.
2. Запусти `start.bat`.
3. При первом запуске скачаются модели (это может занять несколько минут) и откроется окно.
4. Перетащи фото человека в окно. Можно несколько ракурсов — так точнее.
5. Смотри на квадраты: зелёный — он, жёлтый — возможно он, красный — не он.

Клик по маленькому фото эталона убирает его. Кнопка «Очистить эталоны» убирает все.

## Пороги

Два ползунка: «Зелёный от» и «Жёлтый от». Это сходство от 0 до 1.

- Много чужих зелёным — подними «Зелёный от».
- Своего в маске красит красным — опусти «Жёлтый от».

## Видеокарта

На RTX 3050 программа сама возьмёт GPU, если стоят CUDA 12 и cuDNN 9. Без них работает на процессоре — так тоже нормально, i5 тянет. После правок и обновлений перезапусти через `start.bat`.

## Честные ограничения

- Волосы и фон в сравнение почти не входят: лицо выравнивается по глазам и носу, смотрится геометрия лица.
- Медицинская маска переживается частично, балаклава — тяжело: остаются только глаза, точность падает. В этом случае надейся на жёлтый и добавляй эталоны в маске.
- Затылок без лица опознать нельзя ни по какому фото — там нет точек лица. Программа честно красит такое красным, а не гадает.
- Профиль по одному анфасу предсказать нельзя. Внутри устойчивые к позе признаки плюс зеркальные копии эталонов, но надёжнее просто докинуть фото в профиль.
- Проверка «живой человек, а не фото на телефоне» — вероятностная: движение, муар экрана, рамка телефона, блики, моргание. Обычное фото на экране ловится, но качественное видео на хорошем экране может обмануть.
